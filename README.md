CHUNITHM 开源桌面启动器与游戏环境管理工具。

整合游戏启动、MOD / 插件管理、segatools 配置、服务器切换等常用功能。

项目基于 **Tauri 2 + Rust + Vue 3 + TypeScript** 开发

> 项目目前仍在积极开发中，部分功能已经实现，部分功能正在开发或规划中。

## 主要功能

### 🎮 游戏启动器
* 一键启动/停止游戏
* 检查游戏进程状态
* 防止重复启动游戏
* 自动清理残留的 `amdaemon` 进程
* 自定义启动参数

### 🧩 MOD / 插件管理器

* 查看、启用 / 禁用插件
* 导入自定义 DLL
* 内置插件管理

### ⚙️ Segatools 可视化配置

* DNS / AimeDB / Keychip
* VFS / GPIO / IO3
* FPS / 显示模式
* 窗口模式
* Aime

### 🌐 服务器快捷切换
* **RinNET**
* **MuNET**
* **自定义服务器**
